Sobre o Projeto

Este projeto foi desenvolvido com inspiração no livro "A VOZ DA FLORESTA - anuncia eleições dos bichos" da autora Alina Perlman.

A ideia foi criar uma urna eletrônica funcional para trabalhar o conceito das eleições de forma lúdica com crianças de 5 a 10 anos de idade.
